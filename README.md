## Automation workflow

The repository contains one GitHub Actions workflow, `.github/workflows/snake.yml`. It runs daily at `00:00` UTC or can be started manually. The workflow:

1. Checks out the repository.
2. Runs `Platane/snk/svg-only@v3` for the GitHub user `Mahiamk`.
3. Generates light and dark SVG contribution-graph assets.
4. Publishes the generated `dist` directory to the `output` branch using `crazy-max/ghaction-github-pages@v4`.

The workflow requests write access to repository contents and uses the Actions-provided `GITHUB_TOKEN`. The README references the generated light asset at `output/github-contribution-grid-snake.svg`.
